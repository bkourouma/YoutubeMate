# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, without modification.

The full text is published at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

It is available in many languages, including French:
<https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/>

## Scope

It applies in this repository — issues, pull requests, discussions, code review — and
anywhere someone is representing the project in public.

## Reporting

Report a concern privately to the maintainer through GitHub.

> **Owner to complete:** add a monitored contact address here. No address is invented in
> this file, because a wrong one silently drops reports — which is worse than none.

Reports are handled confidentially. The maintainer will not act on a report without
reading it, and will say what was decided.
